# AlinLab — Онлайн-платформа обучения

Полноценный веб-проект (Backend + Frontend) для онлайн-платформы обучения (аналог GetCourse без функций онлайн-оплаты).

## 🛠 Технологический стек
- **Backend**: Python (FastAPI), PostgreSQL (SQLAlchemy ORM), JWT авторизация
- **Frontend**: React.js (Vite), Tailwind CSS (Тема в эстетичном мягком пастельном стиле), Lucide Icons
- **Роли**: Студент (экран-заглушка VS доступные видеоуроки с таймером), Администратор (управление пользователями, выдача доступов, добавление уроков).

## 🚀 Запуск проекта

### Backend:
```bash
cd backend
pip install -r requirements.txt
python run.py
```

### Frontend:
```bash
cd frontend
npm install
npm run dev
```
